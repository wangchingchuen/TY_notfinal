二、實際執行順序

python main.py [命令列參數]
  ↓
if __name__ == "__main__"：呼叫 main()
  ↓
ArgumentParser 讀取 --images-root、--output-csv、--device、--trash-weights
  ↓
Config() 建立預設設定；若使用者有輸入命令列值，就覆寫對應欄位
  ↓
LitteringPipeline(cfg)：建立垃圾偵測器、人車偵測器、事件判定器
  ↓
run_on_all(Path(cfg.images_root))：尋找所有影片資料夾
  ↓
每支影片：reset → 依 frame 編號排序 → 每張圖做垃圾/人車偵測 → Matcher 判定
  ↓
所有 LitteringEvent 轉成 rows，再建立 pandas.DataFrame
  ↓
df.to_csv(cfg.output_csv)：輸出 CSV
